# 🚦 Proyecto simulador trafico — Traffic Simulator (Java)

📍 Madrid, Spain · Author/Autor: **Jesús Sancho Hagen**  
Event-driven traffic simulator written in **Java** using **OOP**. It supports a **GUI mode (Swing)** for interactive visualization and a **batch/console mode** that reads events from **JSON** and outputs a full simulation report in **JSON**.

Simulador de tráfico **dirigido por eventos** en **Java** usando **POO**. Incluye **modo GUI (Swing)** para visualización/control y **modo batch/consola** que lee eventos desde **JSON** y genera un reporte completo en **JSON**.

---

## ✅ Features / Características

- Tick-based simulation + scheduled time events / Simulación por ticks + eventos programados por tiempo
- GUI (Swing) interactive visualization / GUI (Swing) para visualizar e interactuar
- Batch/console execution with JSON input + JSON output / Ejecución batch con entrada JSON + salida JSON
- Layered architecture: model / control / view / Arquitectura por capas: model / control / view
- Observer pattern for UI updates / Patrón Observer para actualizar la interfaz

---

## ▶️ Run / Ejecución

**Main class / Clase principal:** `simulator.launcher.Main`  
Modes / Modos: `gui` (default/por defecto) and `console` (batch)
